# Ecossistema do Leão — Plugin CEO/Fundador

Plugin de gestão para Leonardo Amaral como CEO/fundador da Amaral e Melo Advogados e cofundador da Agricompany Agropatrimonial.

## O que faz

Automatiza rotinas de gestão, governança e comunicação de marca do ecossistema: briefing matinal, reuniões de sócios, pipeline comercial, criação de conteúdo e análise de posicionamento estratégico.

## Comandos

| Comando | O que faz |
|---------|-----------|
| `/meu-dia` | Briefing matinal: agenda, prioridades, pendências, prazos críticos |
| `/pauta-socios` | Monta pauta para reunião de sócios (Coração do Leão) |
| `/pipeline` | Visão consolidada do pipeline comercial do escritório e Agricompany |
| `/post-linkedin` | Rascunha post LinkedIn no tom RARO (≤1.300 chars) |
| `/posicionamento` | Análise estratégica de posicionamento com frameworks RARO |

## Skills

| Skill | O que cobre |
|-------|-------------|
| `governanca-leao` | Framework das 5 dimensões, OKRs, dashboard semanal, indicadores por guardião |
| `marca-raro` | DNA de marca, tom de voz por canal, temas recorrentes, exemplos de posts |

## Integrações

Conecta com Google Calendar, Gmail e Notion para puxar agenda, e-mails e tarefas automaticamente.

## Uso

```
/meu-dia                           # Briefing matinal
/pauta-socios próxima segunda      # Pauta para reunião de sócios
/pipeline                          # Status do pipeline
/post-linkedin IR na atividade rural   # Post sobre IR rural
/posicionamento novo produto de mentoria   # Análise de posicionamento
```
